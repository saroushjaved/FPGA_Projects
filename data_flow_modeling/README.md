# Dataflow Modeling Verilog Examples

This project shows dataflow-style Verilog design using continuous assignments and structural composition. It includes a 4-to-1 mux, an edge-triggered D flip-flop, a T flip-flop, and a parameterized ripple counter.

## Contents

- `Source`: mux, flip-flop, and ripple-counter RTL
- `TestBench`: mux and ripple-counter simulation files

## Keywords

Verilog dataflow modeling, ripple counter, T flip-flop, D flip-flop, FPGA RTL examples, digital design.

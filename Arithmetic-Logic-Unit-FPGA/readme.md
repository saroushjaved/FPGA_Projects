# Arithmetic Logic Unit FPGA

This project contains a Verilog FPGA ALU that cycles through preset operands and performs arithmetic, shift, rotate, logic, and comparison operations selected by a 4-bit opcode.

## Contents

- `Source`: standalone ALU RTL
- `TestBench`: basic simulation stimulus for operand selection and ALU operations

## Keywords

FPGA ALU, Verilog arithmetic logic unit, Xilinx FPGA project, RTL arithmetic, digital logic, Verilog testbench.

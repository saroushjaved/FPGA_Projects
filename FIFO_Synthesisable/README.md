# Synthesizable FIFO Verilog

This project implements a parameterized synchronous FIFO in Verilog. It includes a memory module and FIFO controller with write/read pointers, occupancy counter, and status flags for empty, full, first, last, and second-last states.

## Contents

- `Source`: FIFO memory and top-level FIFO controller
- `TestBench`: reserved for future simulation files

## Keywords

Synthesizable FIFO, Verilog FIFO, FPGA memory buffer, RTL FIFO design, synchronous FIFO, Vivado Verilog.

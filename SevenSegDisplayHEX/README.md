# Hex to Seven Segment Display Verilog

This project implements a hexadecimal to seven-segment display decoder in Verilog. It maps 4-bit hex input values from `0` to `F` into active-low segment patterns with decimal-point control.

## Contents

- `Source`: hex-to-seven-segment decoder RTL
- `TestBench`: simulation sequence for hex digit outputs

## Keywords

Verilog seven segment display, hex decoder, FPGA display controller, active low seven segment, RTL decoder, digital logic project.

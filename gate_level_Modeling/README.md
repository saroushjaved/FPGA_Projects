# Gate Level Modeling Verilog

This project contains gate-level Verilog examples built from primitive logic gates. The cleaned version keeps the complete gate-level 4-to-1 multiplexer and one-bit full adder RTL examples.

## Contents

- `Source`: primitive-gate mux and one-bit full-adder modules
- `TestBench`: mux simulation testbench

## Keywords

Verilog gate level modeling, FPGA logic gates, 4 to 1 mux, full adder Verilog, digital logic design, RTL basics.

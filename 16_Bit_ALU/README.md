# 16-Bit ALU Verilog Project

This FPGA project implements a 16-bit arithmetic logic unit in Verilog. It includes a simple behavioral ALU and a modular vertically partitioned ALU that separates add, subtract, multiply, divide, modulo, shift, and bitwise AND operations into reusable RTL blocks.

## Contents

- `Source`: ALU datapath modules and operation-specific Verilog files
- `TestBench`: simulation testbench for the modular ALU

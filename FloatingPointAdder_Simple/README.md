# Simple Floating Point Adder Verilog

This project implements an educational 13-bit floating-point adder in Verilog. Each operand uses 1 sign bit, 8 significand bits, and 4 exponent bits. The design aligns exponents, handles signed add/subtract behavior, and outputs the same compact floating-point format.

## Contents

- `Source`: floating-point adder RTL
- `TestBench`: directed simulation vectors for common add/subtract cases

# Behavioral Modeling Verilog Mux

This project demonstrates behavioral modeling in Verilog using a 4-to-1 multiplexer. The output is selected with a `case` statement, making it a compact example for learning RTL control logic.

## Contents

- `Source`: behavioral 4-to-1 mux RTL
- `TestBench`: reserved for future simulation files

## Keywords

Verilog behavioral modeling, 4 to 1 mux, FPGA beginner project, RTL multiplexer, Vivado HDL example.

# DIT FFT Verilog Project

This project implements a decimation-in-time FFT datapath in Verilog. The design builds an 8-point FFT from 2-point and 4-point stages, with fixed-point complex multiplication support for twiddle-factor style processing.

## Contents

- `Source`: 2-point FFT, 4-point FFT, 8-point FFT, top-level FFT, and complex multiplier RTL
- `TestBench`: simulations for individual FFT stages and the main FFT module

## Keywords

Verilog FFT, decimation in time FFT, fixed-point FFT, FPGA DSP project, RTL signal processing, Vivado FFT.
